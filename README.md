# 植物大战僵尸杂交重制版 · 受伤反馈

**简体中文** · [English](./README.en.md)

当植物掉血、护甲受损或格盾吸收伤害时，游戏会把事件发给这个 Windows 桌面程序。你可以只在运行面板里看提示，也可以连接郊狼 3.0，让选定的 A / B 通道按预设波形反馈。僵尸受伤可以单独开启。

当前桌面版为 **1.0.0.6**，不依赖 DGHub。**扫码只配对，不会自动开始反馈；强度变化作用于波形，不改手机 App 里手动设置的通道档位。**

## 下载与启动

1. 在本仓库页面点 **Code → Download ZIP**，把压缩包**完整解压**到一个文件夹。
2. 双击根目录的 **`启动.exe`**。不要单独复制 EXE，它需要旁边的 `app` 和 `launcher` 文件夹。
3. 首次启动会联网下载并校验约 **170 MiB** 的运行组件。准备好后会打开独立桌面窗口；以后使用本机缓存，无需重复下载，也不用自己安装 Python、Node.js 或 DGHub。

| --- | -------------------------------------------------------------------------------- |
| 电脑  | Windows x64                                                                      |

## 第一次玩

1. **准备游戏 Mod** 先关闭游戏，在「反馈设置 → 游戏 Mod」保留默认的「自动安装游戏端 Mod」。启用插件时会尝试安装观察器；安装完成后再启动游戏。如果无法自动安装，可以手动导入 [PVZHybrid-Watcher.pmod](app/resources/backend/app/core/PVZHybrid-Watcher.pmod)，在游戏里启用并重启。
2. **连接手机** 先在手机 App 中连接郊狼，再让手机和电脑接入同一局域网。在桌面「设备连接」选手机 **App 版本**，地址保留「自动选择」，点「生成配对码」，用 App 内的 **Socket** 扫码入口扫描。使用 App 4.x 时，如出现设备列表，再选择已连接的郊狼。
3. **选择反馈并启用** 在「反馈设置」选好模式、输出通道和波形，再点「启用插件」。如果设备已经就绪，确认后即可响应游戏事件；如果先启用了插件、后来才连接设备，待通道就绪后再点「允许本次设备反馈」。随时可以点「停止反馈」。
4. **进关卡验证** 默认监听植物受伤。让植物实际受到一次伤害，去「运行面板 → 最近提示」查看；要监听僵尸，在「触发事件」里打开「僵尸受伤」。左侧「连接状态」会显示配对地址、诊断，以及 A / B 通道的当前值和上限。

## 可以怎么调

- **反馈节奏：**「经典单次」两次反馈至少间隔 5 秒；「持续节奏」适合同一个目标连续受伤。输出可以选 A、B 或 A+B。波形预览只显示曲线，不会试播。
- **强度反馈：** 植物和僵尸可分别设置增量。临时提升会在设定时间后回落；累积模式会保留增量，直到达到设定上限。

## 常见问题

**手机提示“服务器连接失败”？** 保持桌面窗口打开，重新生成配对码并在两分钟内扫描。如果仍失败，用手机浏览器打开二维码下方显示的 `/check` 地址：能看到「已连到电脑的配对端口」，说明网络已通，接着看桌面的「连接诊断」；打不开则先确认两端在同一局域网，多网卡时可手动选择电脑实际使用的 Wi-Fi 或以太网 IPv4。

**App 已配对，为什么没有反馈？** 先看「最近提示」有没有新事件。没有提示，检查游戏观察器是否启用、安装后是否重启游戏，以及对应的触发事件是否打开。有提示但设备无反应，再看左侧所选通道是否就绪：例如 `0 / 17` 表示当前档位是 0、上限是 17，并不是正在以 17 输出。档位由你在手机上控制，桌面程序不会替你调高。
